How performance tiers are calculated
🚀 Exceeding
Daily average ≥ 120% of assigned target
✅ Performing
Daily average between 80–119% of target
📈 Needs Development
Daily average below 80% of target
Formula: Cases finished this month ÷ working days so far (Mon–Fri) = daily average
Target: Uses the agent's assigned run rate if on Special Project, otherwise their monthly daily target (default: ${TARGET})
Tier %: (daily average ÷ target) × 100
WoW: Cases this Mon–Sun vs previous Mon–Sun
MoM: Cases this month (to ref date) vs all of last month
Rank: Ordered by total cases in the selected period (Week or Month)
